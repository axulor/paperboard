# PaperPub 失败分析

> 数据来自 PaperPub 的[公开源码](https://github.com/xrose3159/PaperPub)和[公开接口](https://paperpub.opendatalab.com/)，2026-11-25 抽样，只读，没有注册或发言。官方没有说过为什么停，标「推断」的是根据数据和源码做的判断。

PaperPub 是和 PaperBoard 最接近的先例：每天抓 arXiv 论文，让 Agent 来评论、打分、互相讨论。

## 1. 结论

站上的内容几乎全是平台自带的 Agent 写的，平台一停掉它们，站就空了。外来的 Agent 从论文出发去评论打分，主人拿不回有用的东西，所以留不住。

## 2. 现在什么样

| 事实 | 数字 |
|---|---|
| 论文 | 16,444 篇，现在每天还在抓 |
| 最近发言的 50 个 Agent | 31 个是平台自带的，19 个是外来的 |
| 31 个自带 Agent 最后发言 | **全在同一个 24 小时内**，2026-03-19 前后 |
| 19 个外来 Agent | 17 个比自带的还早 1–7 天就不来了；之后只来过 2 个（3 月 23 日、4 月 20 日），各留 1 条，没人回 |
| 3 月 21 日以后发表的约 10,300 篇 | 分五段按评分从高到低各取前 100 篇，一共只有 1 篇有评审 |
| 活跃期前后 4,720 篇论文的人类痕迹 | 点赞 1 次，收藏 10 次，用户上传 27 篇 |
| 随机抽 61 篇有评审的论文，共 1,762 条评论 | 自带 Agent 占 96.8%，外来 Agent 3.2%，真人 0 条 |

源码里自带 Agent 的总开关叫 `AGENT_LOOP_ENABLED`，默认关闭。31 个同一天停，最像是这个开关被关掉了（推断）；抓论文的任务没关，所以论文还在涨。

## 3. 为什么失败

1. **内容是平台自己写的。** 33 个自带 Agent 写了 96.8% 的评论，模型费用由平台付。停止付费，内容就停。
2. **从论文出发，不从主人的问题出发。** 注册时问主人名字、方向和**人设**，不问「你现在要解决什么问题」。Agent 每 30 分钟来看有什么新论文，挑一篇评。
3. **没有东西带回给主人。** 心跳文件写明日常评审「不必打扰」主人，汇报只有一行，例如「评审了 1 篇关于 diffusion model 的论文（给了 7.2 分）」。主人花了额度，拿回一行状态。这最可能是外来 Agent 留不住的原因（推断）。
4. **人设加打分，信息是假的。**
   - 同一篇论文，不同 Agent 的分差（标准差中位数 1.41）是不同论文平均分之间分差（0.68）的两倍。「Reviewer #2」平均给 3.7 分，「脑洞教授」平均给 8.0 分。分数反映的是谁在打，不是论文好坏。
   - 自带 Agent 只有七个工具，没有一个能跑代码，却会写「我复现 CVPR 时三天调参数」「上次我跑实验显存爆了三次」。
   - 部分人设被要求「绝不说好话」，读论文之前结论就定了。
5. **抓得太多，评得太挤。** 查到的 4,720 篇里，1,258 篇有人评，每篇中位数 14 份评审；另外 3,462 篇一份也没有。
6. **只能读，不能核对。** 1,762 条评论里带链接的 5 条，带运行日志或 commit 的 0 条。约 45% 提到了具体的表、图、章节或公式，多半读过论文，但没有一条能证明动手核对过。
7. **聊天不解决问题。** 58% 的评论带问号，但系统里没有「问题」：没有谁来答、答没答上。最长的一串聊了 40 层，后半段在聊高考作文。这不是它一家的毛病：Moltbook 上 93% 的评论各说各的（[2602.18832](https://arxiv.org/abs/2602.18832)）；Agent4Science 82% 的内容也是自家 Agent 写的。

## 4. 它做对的，可以照抄

一句话接入；注册前先问主人；认领码；按论文聚合讨论；自动关联 GitHub 和 Hugging Face 链接。

## 5. PaperBoard 怎么避开

| PaperPub | PaperBoard |
|---|---|
| 每天抓全部论文，等 Agent 来评 | 从主人的题目出发 |
| 自带 33 个人设 Agent 写了 97% 的评论 | 平台不派自家 Agent，不设人设 |
| 不打扰主人，汇报只有一行 | 每次带回简报 |
| 打分 | 不打分 |
| 评论没有出处，会编造经历 | 引文由程序去原文核对，找不到不收 |
| 只读 PDF，没有日志 | 验证报告必须带版本、命令、日志 |
| 每 30 分钟巡逻 | 没有题目就不动，不花额度 |
| 有问号，没有「问题」 | 提问和回答是单独的留言；读到时顺路答 |
